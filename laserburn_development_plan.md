# План разработки аналога LightBurn для ЧПУ TwoTrees (Ubuntu, Python)

Этот документ содержит пошаговый план создания управляющего ПО для лазерного ЧПУ-станка на базе **Python**, **PyQt6** и **pySerial**. Программа включает систему слоев, управление мощностью/скоростью лазера и интерактивный холст.

---

## 🛠 Стек технологий
* **Язык:** Python 3.10+
* **Интерфейс (GUI):** PyQt6 (мощный графический фреймворк)
* **Работа со станком:** pySerial (обмен данными по протоколу GRBL)
* **Векторная геометрия:** Shapely / ezdxf (опционально для импорта DXF/SVG)
* **Сборка в бинарник:** PyInstaller (компиляция в один исполняемый файл для Ubuntu)

---

## 🗺 Пошаговый план разработки

### Этап 1: Архитектура данных и Интерфейс (GUI)
**Цель:** Создать каркас приложения с графическим холстом и таблицей слоев.
* [ ] **1.1. Структура проекта:** Создать модульную структуру (`main.py`, `gui.py`, `core.py`, `serial_worker.py`).
* [ ] **1.2. Менеджер Слоев:** Создать класс `Layer` (id, цвет, скорость, мощность, режим: Срез/Гравировка).
* [ ] **1.3. Сетка интерфейса (PyQt6):**
  * **Центр:** `QGraphicsView` — холст, отображающий рабочую зону станка (например, 400x400 мм).
  * **Справа:** Панель слоев (таблица с возможностью менять настройки для каждого цвета).
  * **Снизу/Сбоку:** Консоль GRBL и панель подключения к COM-порту (`/dev/ttyUSB0`).

### Этап 2: Графический холст и Векторные объекты
**Цель:** Научить программу отображать геометрию и привязывать её к слоям.
* [ ] **2.1. Инструменты рисования:** Реализовать базовое добавление примитивов (линия, прямоугольник, окружность) на холст.
* [ ] **2.2. Привязка к слоям:** Привязать каждый графический объект к конкретному слою. При изменении цвета слоя в таблице объект на холсте должен менять цвет.
* [ ] **2.3. Масштабирование:** Добавить зум колесиком мыши и перемещение по холсту (Pan/Zoom).

### Этап 3: Компилятор G-Code
**Цель:** Переводить графические объекты в текстовые команды, понятные прошивке GRBL.
* [ ] **3.1. Сортировка по слоям:** Скрипт должен обходить объекты строго в порядке приоритета слоев.
* [ ] **3.2. Генерация траекторий:** 
  * Перевод координат из пикселей экрана в миллиметры станка.
  * Формирование команд перемещения (`G1 X... Y... F...`).
* [ ] **3.3. Управление лазером:** Внедрение команд мощности лазера (`M4 S...` для динамического режима или `M3 S...` для постоянного, `M5` для выключения) на основе настроек выбранного слоя.

### Этап 4: Потоковый Sender (Связь по Serial)
**Цель:** Безопасная отправка команд на станок без зависания интерфейса.
* [ ] **4.1. Многопоточность (`QThread`):** Создать отдельный поток для работы с Serial-портом.
* [ ] **4.2. Протокол GRBL (Ping-Pong):** Реализовать алгоритм: отправка строки G-code -> ожидание ответа `ok` или `error` от станка -> отправка следующей строки.
* [ ] **4.3. Интерактивное управление:** Кнопки «Старт», «Пауза», «Стоп», а также ручное перемещение (Джойстик / Jogging).

### Этап 5: Финальная сборка (Компиляция)
**Цель:** Получить готовый `.bin` файл для запуска на Ubuntu.
* [ ] **5.1. Тестирование:** Проверка отправки команд в режиме симулятора станка.
* [ ] **5.2. Упаковка через PyInstaller:** Выполнение команды:
  ```bash
  pyinstaller --onedir --windowed --name="LaserBurn_Analogue" main.py
  ```
* [ ] **5.3. Права доступа:** Добавление пользователя в группу `dialout` в Ubuntu для работы с USB-портом без root-прав:
  ```bash
  sudo usermod -a -G dialout $USER
  ```
