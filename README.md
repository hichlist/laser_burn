# LaserBurn Analogue

Управляющее ПО для лазерных гравёров на GRBL 1.1 (TwoTrees и аналоги), аналог LightBurn.
Python 3.10+, PyQt6, pySerial. План разработки: `laserburn_development_plan.md`.

## Возможности

- Холст рабочего поля в мм (по умолчанию 400×400), сетка, зум колесом, панорама средней кнопкой, «Вписать поле» (Ctrl+0).
- Инструменты: выделение (рамкой, перемещение мышью и стрелками, Shift — шаг 10 мм), линия, прямоугольник, эллипс, полилиния
  (клик — точка, двойной клик / Enter / ПКМ — завершить, клик в первую точку — замкнуть). Shift — квадрат, круг, угол 45°.
  Привязка к сетке 1 мм.
- Отмена и повтор действий: Ctrl+Z / Ctrl+Shift+Z (или Ctrl+Y), меню «Правка» и кнопки на панели. Отменяются рисование,
  перемещение, удаление, импорт, смена слоя объектов и любые изменения слоёв.
- Слои: цвет, режим «Срез» (по контуру) или «Гравировка» (построчная заливка замкнутых контуров), скорость, мощность,
  проходы, интервал строк, вывод вкл/выкл, M3 (постоянная мощность) или M4 (динамическая). Порядок слоёв задаёт порядок выполнения.
- Импорт SVG и DXF: цвета файла превращаются в слои, импорт центрируется на поле.
- Компилятор G-code: сортировка контуров «ближайший следующий», двунаправленная гравировка, оценка времени, предпросмотр (Ctrl+P), экспорт (Ctrl+E).
- Станок: подключение к `/dev/ttyUSB*`/`/dev/ttyACM*`, отправка в отдельном потоке (QThread) по схеме ping-pong (строка → `ok`/`error` → следующая),
  старт/пауза (feed hold)/стоп (feed hold + soft reset), jog, хоминг, `$X`, «Задать ноль здесь», «Рамка», консоль GRBL с историей команд.
  Ошибка или авария станка останавливает задание.
- Порт `SIMULATOR` — встроенный симулятор GRBL для проверки без станка.
- Проект сохраняется в `*.lbrn.json`.

## Сборка и установка

```bash
./build.sh                  # собирает один исполняемый файл dist/laserburn (venv создаётся сам)
./install.sh                # ставит для текущего пользователя: ~/.local/bin/laserburn + ярлык в меню
./install.sh --system       # или для всех пользователей в /usr/local (через sudo)
./install.sh --uninstall    # удалить (добавьте --system, если ставили для всех)
```

`install.sh` сам запустит сборку, если `dist/laserburn` ещё нет. После установки программа есть в меню приложений
(«LaserBurn Analogue», можно закрепить в доке) и запускается из терминала командой `laserburn`
(если `~/.local/bin` только что появился, команда заработает после перелогина).
Файл `dist/laserburn` самодостаточен: его можно скопировать на другой компьютер с Ubuntu и запустить без Python.

Доступ к USB-порту без root (нужно перелогиниться):

```bash
sudo usermod -a -G dialout $USER
```

## Настройка станка

### TwoTrees TTS-10 Pro

Станок построен на ESP32 с прошивкой, совместимой с GRBL 1.1, подключается по USB на 115200 бод, рабочее поле 300×300 мм.
На реальном станке программа пока не проверялась — только на встроенном симуляторе, поэтому первые запуски делайте осторожно.

1. **Поле.** Меню «Станок → Настройки станка»: ширина и высота 300 мм (по умолчанию стоит 400×400).
2. **Подключение.** Панель «Станок»: порт обычно `/dev/ttyUSB0` или `/dev/ttyACM0` (если списка нет — кнопка ⟳),
   скорость 115200, «Подключить». Для доступа к порту пользователь должен быть в группе `dialout` (см. выше).
3. **Проверка прошивки.** В консоли отправьте `$$` и проверьте:
   - `$32=1` — лазерный режим. Если там `0`, отправьте `$32=1`. Без него станок останавливается в каждой точке
     и не выключает лазер на холостых перемещениях.
   - `$30` — максимальное значение S. Впишите это число в «Макс. мощность S» в настройках станка,
     иначе проценты мощности слоёв не будут соответствовать реальной мощности.
4. **Ноль заготовки.** Координаты задания отсчитываются от рабочего нуля. Если у станка нет концевиков, хоминг (⌂)
   вернёт ошибку — тогда подведите голову к левому нижнему углу заготовки кнопками перемещения
   и нажмите «Задать ноль здесь».
5. **Первое задание.** Поставьте мощность 5–10%, нажмите «Рамка», чтобы проверить положение заготовки,
   наденьте защитные очки и только потом «Старт».

Ограничения по сравнению с LightBurn и родным ПО TwoTrees:

- **Нет растровой гравировки** фотографий и картинок (JPG/PNG/BMP) — только векторы: фигуры, SVG, DXF.
- **Нет Wi‑Fi** — только USB.
- **Гравировка заливкой на высоких скоростях** может идти рывками: строки отправляются по одной с ожиданием `ok`,
  и между множеством коротких строк возникают паузы. Резки по контуру это почти не касается.

### Совместимость с другими станками

| Станки | Статус |
|---|---|
| Диодные лазеры на GRBL 1.1 по USB: TwoTrees, Ortur, Atomstack, Sculpfun, Creality Falcon, NEJE и т.п. | работает |
| GRBL_ESP32 и FluidNC по USB | работает |
| CO2-лазеры на контроллерах с GRBL | скорее всего, работает (команды те же), не проверялось |
| CO2 с контроллерами Ruida, Trocen, TopWisdom | не работает: свой протокол, не G-code по serial |
| K40 со штатной платой M2 Nano, гальво-маркеры (EZCAD/BJJCZ) | не работает |
| Станки на Marlin и Smoothieware | не работает: другие ответы и управление лазером |
| Фрезерные ЧПУ на GRBL | подключится, но не годится: нет оси Z и управления шпинделем, только движения X/Y с лазером |

## Разработка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python main.py            # можно передать проект .lbrn.json, .svg или .dxf
.venv/bin/python -m pytest          # GUI-тесты идут в offscreen-режиме
```

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | точка входа |
| `build.sh`, `install.sh` | сборка в один файл и установка в систему |
| `laserburn/resources/` | иконка программы |
| `laserburn/core.py` | слои, фигуры, документ, сохранение проекта |
| `laserburn/gcode.py` | компилятор G-code, заливка, оптимизация обхода |
| `laserburn/grbl.py` | протокол GRBL без Qt: потоковая отправка, статус, пауза/стоп |
| `laserburn/grbl_sim.py` | симулятор GRBL |
| `laserburn/serial_worker.py` | поток обмена с портом (QThread) |
| `laserburn/importers.py` | импорт SVG/DXF |
| `laserburn/canvas.py` | холст и инструменты рисования |
| `laserburn/panels.py` | панели слоёв, станка и консоли |
| `laserburn/gui.py` | главное окно, предпросмотр, настройки |
